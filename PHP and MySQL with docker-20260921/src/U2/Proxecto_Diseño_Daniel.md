**Descripcion**

Aplicación para unha protectora de animales na que se poderá

- Paxina de inicio na ver os animais dispoñibles para adopción
- Unha paxina para pedir o seu nome gardalo nunha cookie e mostrar unha mensaxe
-  Paxinas para engadir modificar  e eliminar na animais base de datos
-  A taboa tera os campos Tipo de animal, nome, raza, xenero, anos
